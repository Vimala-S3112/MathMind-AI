About Performance Prediction

This section predicts student performance using existing student records. The prediction is calculated using previous marks, attendance and current marks. Select a student to view the predicted result and performance graphs.

📐 Prediction Formula

Predicted Score = (Previous Marks × 0.4) + (Attendance × 0.2) + (Current Marks × 0.4)

Previous Marks: Previous academic performance.

Attendance: Student attendance percentage.

Current Marks: Current examination marks.

0.4, 0.2, 0.4: Weights assigned to each factor.
