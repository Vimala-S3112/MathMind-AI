🧠 About MathMind AI

MathMind AI is a Student Performance Prediction Website designed to analyze student academic performance using mathematical concepts and data science techniques.

📖 Project Overview

MathMind AI helps to understand student performance through marks, attendance and academic data. It provides mathematical analysis, performance prediction and model comparison in a simple and interactive interface.

🎯 Project Objectives

  • Analyze student academic performance.
  • Calculate statistical measures.
  • Predict student performance using a demo formula.
  • Compare machine learning model evaluation metrics.
  • Provide useful academic support suggestions.

⭐ Main Features

📊 Dashboard

Displays student performance summaries and charts.

👨‍🎓 Student Data

Displays student marks and attendance details.

📐 Mathematical Analysis

Shows statistical calculations and visualizations.

🔮 Performance Prediction

Demonstrates student score prediction using a weighted formula.

🤖 Model Comparison

Displays sample evaluation metrics of different models.

🎓 Academic Support

Provides study tips and learning suggestions.

💻 Technologies Used

HTML CSS JavaScript Chart.js Python Data Science Machine Learning Concepts
